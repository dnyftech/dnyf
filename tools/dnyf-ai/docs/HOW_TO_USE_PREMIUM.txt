## 🎯 DETAILED WALKTHROUGH

### Setup

**1. Your project directory should look like:**
```
claude-ai/
├─ app_backend.py          (backend server)
├─ index.html              (use index-premium.html)
├─ index-premium.html      (new premium version)
├─ requirements.txt
└─ (other files)
```

**2. Replace the original HTML:**
```bash
cd ~/claude-ai

# Backup original (optional)
cp index.html index-original.html

# Use premium version
cp index-premium.html index.html
```

**3. Verify backend is running:**
```bash
# In terminal 2, make sure this is running:
python app_backend.py

# You should see:
# ============================================================
# 🚀 Claude AI Interface Backend
# ============================================================
# Server: 0.0.0.0:8000
# ...
```

**4. Open browser:**
```
http://localhost:8000
```

### First Use

**1. Initial Interface:**
```
You'll see:
├─ Sidebar (left)
│  ├─ "✨ New Chat" button (green)
│  ├─ Empty conversations list
│  └─ Settings/Dark/Export buttons
│
└─ Main area (right)
   ├─ Header with model selector
   ├─ Empty state "Start a conversation"
   └─ Input field at bottom
```

**2. Send First Message:**
```
1. Click input field (bottom)
2. Type: "Hello"
3. Press Enter or click ↑ button
4. Response appears in real-time
5. Message saved automatically
```

**3. Try Settings:**
```
1. Click ⚙️ Settings (sidebar)
2. Adjust Temperature slider (0 - 2)
3. Adjust Response Length (128 - 2048)
4. See changes reflected immediately
5. Click Close
6. Changes are saved automatically
```

**4. Try Dark Mode:**
```
1. Click 🌙 Dark Mode (sidebar)
2. Entire interface switches to dark
3. Settings saved automatically
4. Click again to switch back
```

### Regular Use

**New Conversation:**
```
1. Click "✨ New Chat" button
2. Start typing
3. Conversation auto-saved
4. Appears in sidebar
```

**Load Previous Chat:**
```
1. See list in sidebar
2. Click any conversation
3. Loads all previous messages
4. Continue from where you left off
```

**Delete a Conversation:**
```
1. Hover over conversation in sidebar
2. Click ✕ (delete button)
3. Conversation removed
4. Can't be undone
```

**Copy a Message:**
```
1. Hover over assistant message
2. Click 📋 (copy button)
3. Message copied to clipboard
4. Paste anywhere
```

**Delete Your Message:**
```
1. Hover over your message (user)
2. Click 🗑️ (delete button)
3. Message removed from conversation
4. Deleted from history too
```

**Export Conversation:**
```
1. Click ⬇️ Export Chat (sidebar)
2. File downloads as .txt
3. Filename: chat-TIMESTAMP.txt
4. All messages included
5. Can share or archive
```

**Clear All History:**
```
1. Click ⚙️ Settings
2. Scroll to "Data Management"
3. Click "🗑️ Clear All Conversations"
4. Click "Yes" to confirm
5. All conversations deleted
6. Resets to empty state
```

## 🎨 CUSTOMIZATION

### Change Accent Color

**Find this in index.html (line ~30):**
```css
:root {
    --accent: #10a37f;        /* Change this */
    --accent-dark: #0d8659;
    --accent-light: #d1fae5;
}
```

**Change to your color:**
```css
:root {
    --accent: #3b82f6;        /* Blue example */
    --accent-dark: #1d4ed8;
    --accent-light: #dbeafe;
}
```

Then refresh browser - all blue accents everywhere.

### Change Sidebar Width

**Find this (line ~100):**
```css
.sidebar {
    width: 280px;  /* Change this */
}
```

**Examples:**
```css
width: 320px;     /* Wider sidebar */
width: 240px;     /* Narrower sidebar */
width: 350px;     /* Maximum comfortable width */
```

### Change Default Temperature

**Find this (line ~800 in JavaScript):**
```javascript
return {
    temperature: 0.7,  /* Change this */
    maxTokens: 512,
    theme: 'light',
};
```

**Examples:**
```javascript
temperature: 0.3,     /* More predictable, less creative */
temperature: 0.7,     /* Balanced (default) */
temperature: 1.5,     /* Very creative, unpredictable */
```

### Change Default Token Limit

**In same location:**
```javascript
return {
    temperature: 0.7,
    maxTokens: 512,     /* Change this */
    theme: 'light',
};
```

**Examples:**
```javascript
maxTokens: 256,      /* Shorter responses */
maxTokens: 512,      /* Balanced (default) */
maxTokens: 1024,     /* Longer responses */
```

### Add Custom Font

**Find this (line ~75):**
```css
body {
    font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', 'Helvetica Neue', sans-serif;
}
```

**Change to:**
```css
body {
    font-family: 'Georgia', serif;
    /* or */
    font-family: 'Courier New', monospace;
    /* or any system or web font */
}
```

## 🔧 TROUBLESHOOTING

### Interface loads but no models available

**Fix:**
```bash
# Check if Ollama is running
curl http://localhost:11434/api/tags

# If not running:
ollama serve

# Pull a model if none available:
ollama pull neural-chat
```

### Dark mode doesn't persist

**This means browser localStorage is blocked.**
```bash
# Solution: Use Firefox or Chrome without privacy blockers
# Or check browser settings for localStorage
```

### Messages don't save to sidebar

**Likely localStorage issue.**
```bash
# Clear browser cache
# Or try different browser
# Or check privacy settings
```

### API connection errors

**Make sure backend is running:**
```bash
# Terminal 2 - should show:
python app_backend.py

# Output shows:
# 🚀 Claude AI Interface Backend
# Server: 0.0.0.0:8000
```

### Settings modal stuck

**Press Escape key** to close modal.
Or refresh page.

### Conversation not loading

**Try:**
1. Refresh page
2. Click conversation again
3. Check browser console (F12 → Console)
4. Look for error messages

## 🚀 DEPLOYMENT OPTIONS

### Option 1: Simple File Serving
```bash
# Just use the HTML as-is
# No special server needed
# Works with any HTTP server
```

### Option 2: Python Server
```bash
# From directory with HTML
python -m http.server 3000

# Open: http://localhost:3000
```

### Option 3: Node Server
```bash
# Install http-server (optional)
npx http-server -p 3000

# Open: http://localhost:3000
```

### Option 4: Docker
```dockerfile
FROM nginx:latest
COPY index.html /usr/share/nginx/html/
EXPOSE 80
```

```bash
docker build -t claude-ui .
docker run -p 8080:80 claude-ui
```
