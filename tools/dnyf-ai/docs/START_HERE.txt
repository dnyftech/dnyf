
```bash

# Terminal 2
```

## 🚀 COMMAND CHEAT SHEET

```bash
# Install models (first time)
bash setup-models.sh

# Start Ollama
ollama serve

# Start backend (SmolLM - fastest)
export OLLAMA_MODEL=smollm:135m
python app_backend.py

# Start backend (Gemma3 - better quality)
export OLLAMA_MODEL=gemma3:270m
python app_backend.py

# List installed models
ollama list

# Test model directly
ollama run smollm:135m "Hello"
ollama run gemma3:270m "Hello"
```

## 📊 MODEL COMPARISON

| Feature | SmolLM:135m | Gemma3:270m |
|---------|-----------|-----------|
| Size | 135M params | 270M params |
| Speed | ⚡⚡⚡ Ultra-fast | ⚡⚡ Fast |
| Quality | Good | Better |
| RAM | ~500MB | ~800MB |
| Best for | Mobile/Termux | Complex reasoning |
| Response time | 50-100ms/token | 100-150ms/token |

**Default: SmolLM** (optimal for Termux)
**Switch anytime:** Use dropdown in chat UI

## 🆘 QUICK TROUBLESHOOTING

| Issue | Fix |
|-------|-----|
| "Models not found" | `bash setup-models.sh` |
| "Connection refused" | Make sure `ollama serve` is running |
| "Port 8000 in use" | `PORT=5000 python app_backend.py` |
| Slow responses | Use `smollm:135m` (smaller, faster) |
| Out of memory | Check with `free -h` |
