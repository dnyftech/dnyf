## 🆘 IF SOMETHING GOES WRONG

### "Models not found"

```bash
ollama pull smollm:135m
ollama pull gemma3:270m
ollama list  # Verify
```

### "Port already in use"

```bash
# Kill existing process
pkill -f "python app_backend.py"

# Or use different port
PORT=5000 python app_backend.py
```

### "Connection refused"

```bash
# Make sure Ollama is running
ollama serve

# In another terminal, check:
curl http://localhost:11434/api/tags
```

### "Out of memory"

```bash
# Use smaller model
export OLLAMA_MODEL=smollm:135m
python app_backend.py

# Check RAM
free -h
```

## 💡 PRO TIPS

### Tip 1: Keep Multiple Sessions
```bash
# Terminal 1: Ollama (never stop this)
ollama serve

# Terminal 2: Backend (can restart)
python app_backend.py

# Terminal 3: Monitoring
watch -n 1 'free -h'
```

### Tip 2: Test Models Directly
```bash
# Without starting backend
ollama run smollm:135m "What is AI?"
ollama run gemma3:270m "What is AI?"
```

### Tip 3: Monitor Performance
```bash
# In a separate terminal, watch memory
watch -n 1 'echo "Memory:" && free -h && echo && ps aux | grep -E "ollama|python"'
```

### Tip 4: Automate Startup
```bash
# Create start.sh
#!/bin/bash
ollama serve &
sleep 2
OLLAMA_MODEL=smollm:135m python app_backend.py

# Then: bash start.sh
```
