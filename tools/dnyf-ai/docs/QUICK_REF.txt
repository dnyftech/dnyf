# 🚀 QUICK REFERENCE - SmolLM & Gemma3 Setup

## ⚡ 3-Command Setup

```bash
# 1. Pull both models (first run only, takes time)
ollama pull smollm:135m && ollama pull gemma3:270m

# 2. Start Ollama (Terminal 1)
ollama serve

# 3. Start Backend (Terminal 2) - Choose ONE:
export OLLAMA_MODEL=smollm:135m && python app_backend.py    # Fast ⚡
# OR
export OLLAMA_MODEL=gemma3:270m && python app_backend.py    # Quality ✨
```

**Then open: http://localhost:8000**

## 🔄 Switch Models Anytime

### Method 1: Web UI (Easiest)
Just click the dropdown in the chat. Both are always loaded.

### Method 2: Environment Variable
```bash
export OLLAMA_MODEL=smollm:135m  # or gemma3:270m
python app_backend.py
```

### Method 3: Edit code
In `app_backend.py` line ~20:
```python
DEFAULT_MODEL = "smollm:135m"  # Change this
```

## 🆘 Common Issues

| Problem | Fix |
|---------|-----|
| "No such model" | `ollama pull smollm:135m` |
| Out of memory | Use `smollm:135m` (smaller) |
| Can't connect | Make sure `ollama serve` is running |
| Model not in dropdown | Restart backend after pulling model |

---

## 🎯 Best Practices

✅ **SmolLM (135m):**
- Default for Termux/mobile
- Set `temperature: 0.5` for consistency
- Great for quick questions
- ~50-100ms per token

✅ **Gemma3 (270m):**
- Use for complex reasoning
- Set `temperature: 0.7` for creativity
- Better multi-step problems
- ~100-150ms per token
